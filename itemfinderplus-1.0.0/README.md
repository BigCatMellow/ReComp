# ItemFinderPlus

![ItemFinderPlus banner](banner.png)

A gen1recomp mod that improves one of the most useless Gen 1 items.

While the Item Finder is in your bag, any tile on the current map that hides an item twinkles a gentle white sparkle:

- Out of range — a small, subtle sparkle
- Within the Item Finder's detection radius (5 tiles) — a larger, brighter sparkle

![ItemFinderPlus demo — hidden item sparkle](demo.gif)


Behaviour notes

- Sparkles only appear while the Item Finder is in your bag, so remember to get it on Route 11.
- The picked-up items stops sparkling after you grab it.
- Works on Red, Blue and Yellow — it reads the same data the vanilla Item Finder reads
- Game Corner hidden coins will not work with this mod (the vanilla Item Finder doesn't detect them either)

Options

OPTIONS → ITEM FINDER PLUS: ON / OFF (default ON).

Compatibility

- Engine: any 0.x release (>=0.0.0-0 <2.0.0), API level 2.
- Compatible with [Dramatic Shape Voxel Mod](https://github.com/DramaticShape/DramaticShapeVoxelMod)
