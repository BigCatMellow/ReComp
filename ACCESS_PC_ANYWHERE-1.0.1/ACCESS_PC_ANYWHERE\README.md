# Access PC Anywhere

Start menu **PC** opens Bill's PC when available. Otherwise shows a short message.

## OPTIONS

Pause **OPTIONS → ACCESS PC → OPEN**:

- **OVERWORLD ONLY** — ON (default): PC only appears outdoors (towns/routes/plateau), not inside buildings. OFF: PC appears whenever the Start menu is open.

## Install

Enable in the mod manager. No dependencies.
