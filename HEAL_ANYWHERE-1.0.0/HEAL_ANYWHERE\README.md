# Heal Anywhere

Start menu **HEAL ¥N** heals the party for yen and plays a Poké Center machine animation in front of you (2D and voxel).

Cost scales with badge count and how many times you have used it since a nurse heal:

| Badges | 1st use | 2nd | 3rd |
| --- | --- | --- | --- |
| 0 | ¥250 | ¥500 | ¥750 |
| 4 | ¥1200 | ¥2400 | ¥3600 |
| 8 | ¥5000 | ¥10000 | ¥15000 |

Healing at a real Poké Center nurse resets the use counter.

## Install

Enable in the mod manager. No dependencies.
