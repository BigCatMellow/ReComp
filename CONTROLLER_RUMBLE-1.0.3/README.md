# Controller Rumble

Rumble for battle shakes and extras (hits, catch, menus, story beats). Categories and intensity live under OPTIONS → **CONTROLLER RUMBLE** (OPEN).

## Options

- Rumble on/off
- Intensity OFF / LOW / MED / HIGH
- Battle FX / Ambient / Story / Menus

## Install

Drop into `mods/` and enable. Needs a rumble-capable controller and `engine_internals`.
