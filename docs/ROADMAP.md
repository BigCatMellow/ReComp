## Evaluation rule for existing mods

For every feature with an existing community implementation:

1. audit what it does well;
2. identify private-engine coupling and compatibility risks;
3. identify UI/UX friction;
4. compare against current public Gen1Recomp APIs;
5. keep proven logic where it remains the best solution;
6. rewrite or simplify where the Definitive implementation can be better;
7. test the feature against the rest of the unified mod, not only by itself.
